# 澳门数据分析引擎 (Macau Lottery Analyzer)

本项目是一款基于 Android 平台的高级数据分析与预测应用，采用现代化的 Kotlin 与 Jetpack Compose 原生开发。该软件主要用于自动抓取历史开奖数据，并通过内置的算法引擎推演和排除小概率号码（杀号）。

## ✨ 核心特性功能

* 🚀 **开机自动同步**：每次启动软件时，自动连接远程数据源，抓取并同步最新开奖记录，无需人工录入。
* 🧠 **智能推算引擎**：基于历史数据，独家算法深度分析，精准推算下期 6 大排除号（杀号），帮助用户极大地缩小选号范围。
* ⏳ **预测缓冲池校验**：提供 10 期连环预测缓冲池，直观展示“历史推荐”与“实际开奖”的对碰结果（高亮显示命中与警告），用真实数据验证算法准确率。
* 💾 **本地离线持久化**：内置 Room (SQLite) 数据库架构，开奖数据和推演状态持久化保存在手机本地。即使在无网络环境下，也能实现秒级响应与丝滑查阅。
* 🎨 **现代 UI 设计**：采用 Jetpack Compose 打造的沉浸式数据面板，UI 响应迅速、界面清爽直观。
* 🤖 **云端全自动打包**：完美接入 GitHub Actions，代码一键提交即可自动云端编译生成 APK 包，免去本地配置环境的烦恼。

## 🛠️ 技术栈
* **语言**: Kotlin
* **UI 框架**: Jetpack Compose (Material 3)
* **异步与并发**: Kotlin Coroutines & Flow
* **数据持久化**: Room Database
* **CI/CD**: GitHub Actions

## 📦 如何获取安装包？
本项目已配置 GitHub 自动化构建。
1. 点击仓库上方的 **Actions** 标签。
2. 选择最新一次成功（绿色对勾）的构建任务。
3. 在页面最下方的 **Artifacts** 区块下载 `app-debug-apk` 压缩包，解压后即可安装体验。
